# docx-footnotes-dicionario-by-jair-lima

## Descrição
Injeta notas de rodapé nativas do Word a partir de um dicionário de termos, sem alterar a formatação.

## Stack
Python 3.7+, python-docx, lxml, CustomTkinter, PyInstaller (opcional).

## Estrutura
Ver a lista de arquivos na raiz e o README.md.

## Comando essencial
`python docx_footnote_injector.py entrada.docx saida.docx`

## Estado atual
Versão pública inicial (2026-10-17), extraída do projeto original do autor.

## Problemas conhecidos
Testado apenas no Windows.
